# newapi-media

独立的 OpenClaw Skill。复制整个 newapi-media 目录到 OpenClaw 的 workspace/skills 下即可使用。

配置环境变量：

NEWAPI_BASE_URL=https://your-newapi.example.com
NEWAPI_API_KEY=your-api-key

不要把真实 API Key 写入 Skill 仓库。模型名称、接口字段和异步任务格式以实际 NewAPI 文档为准。
