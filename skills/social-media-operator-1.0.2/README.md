# Social Media Operator Skill

已将以下能力统一为一个技能包：

- 小红书：内容创作、卡片渲染、发布准备、搜索浏览、评论互动、爆款结构分析
- 微信公众号：文章监控、竞品追踪、阅读趋势、舆情分析方案
- 抖音：短视频脚本、镜头拆解、完播与互动优化
- 私域：内容配比、用户分层、转化路径
- 通用：选题、内容日历、数据复盘与安全边界

## 正式入口

`skills/social-media-operator/SKILL.md`

## 结构

- `references/`：按平台拆分的详细规则，避免主说明重复膨胀
- `templates/`：小红书正文和卡片渲染输入模板
- `skills/xhs-note-creator/`：旧版渲染脚本与素材，待迁移后只保留一个实现
- `skills/*/SKILL.md`：兼容旧路径的迁移提示，不再作为独立技能入口

## 凭证与合规

Cookie、密钥、账号数据和运行产物不应放入技能包或版本库。涉及官方 API、自动发布、抓取和互动时，遵守平台条款、访问权限、频率限制和隐私要求。
