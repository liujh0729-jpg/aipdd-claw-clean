# 微信公众号监控

## 适用范围

文章发布监控、竞品追踪、阅读趋势、互动数据和舆情分析。微信公众号真实数据通常需要认证后的官方 API 或合法第三方数据源；没有权限时只能输出监控方案，不能伪造数据。

## 推荐字段

| 字段 | 说明 |
|---|---|
| title | 文章标题 |
| author | 作者/账号 |
| publish_time | 发布时间 |
| source_url | 原文链接 |
| read_count | 阅读量 |
| like_count | 点赞数 |
| comment_count | 评论数 |
| keywords | 命中的品牌/行业词 |
| sentiment | 情绪判断及依据 |

## 监控流程

1. 明确账号、关键词、时间范围和目标指标。
2. 选择官方 API、授权数据平台或人工采集方式。
3. 统一字段与时间口径，记录数据来源和采集时间。
4. 识别异常增长、负面集中和竞品内容变化。
5. 输出事实、推断、风险等级与下一步动作。

遵守平台条款、频率限制、版权和个人信息保护要求；不要绕过登录、验证码或访问控制。
