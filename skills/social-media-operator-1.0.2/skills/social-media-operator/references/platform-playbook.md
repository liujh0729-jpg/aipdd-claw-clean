# 平台策略与模板

## 内容日历

每周可用节奏：周一干货、周二故事、周三方法、周四互动、周五案例/软性产品、周六生活化内容、周日复盘。月度按“建立认知 → 用户互动 → 产品验证 → 转化收口”推进，并根据数据调整。

## 小红书

标题用“数字 + 痛点 + 结果”“疑问 + 悬念”“对比 + 反差”等结构，控制在 20 字内。正文使用场景开头、分点价值、真实限制、轻量 CTA；话题混合 1 个大词、2–3 个垂直词、2–3 个长尾词。避免“百分百、最有效、保证”等绝对化表达。

## 公众号

文章结构：结论先行 → 3–5 个分论点 → 案例或可核验数据 → 总结与 CTA。选题优先考虑“热点 + 垂直”“痛点 + 解决”“反差 + 认知”“情感 + 共鸣”。

## 抖音

输出镜头表：镜头号、时长、画面、台词/字幕、音效、转场。开头 3 秒明确冲突或收益，中段每 5 秒给一个信息点，结尾只保留一个主要行动。

## 私域

内容比例可从 40% 价值、30% 生活、20% 互动、10% 产品开始。尊重用户同意与退订意愿，标签只用于服务，不用于歧视性分层。

## 统一输出检查

- 是否写清平台、目标和受众？
- 是否区分事实、推测与建议？
- 是否有清晰 CTA 且不诱导？
- 是否检查标题长度、敏感词、版权和隐私？
