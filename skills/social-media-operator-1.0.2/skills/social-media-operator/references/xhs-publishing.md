# 小红书发布与互动 SOP

## 发布前

图文发布必须齐备：封面/配图、标题、正文。先进入正确的图文发布入口，上传后确认图片已进入编辑区，再填写标题、正文与话题。标题建议不超过 20 字；完成后只停在发布按钮，等待用户确认。

发布页面可能改版，必须以当前页面可见文本和最新快照定位元素，不依赖历史 ref 或固定选择器。每个动作最多重试一次；仍失败就改为手动完成最后一步。

## 评论检查

默认打开通知中的“评论和@”，输出新评论数、最近 3–5 条摘要和风险信号。检查不等于回复，等待用户授权后再处理。

回复时按“目标用户名 → 回复入口 → 输入框占位 → 文案 → 发送 → 成功确认”逐项核对。一次默认只发 1 条，建议不超过 280 字，间隔 8–15 秒。遇到频繁操作、验证码、网络异常或连续两次失败，立即停止。

## 搜索与浏览

从搜索结果页进入帖子，默认跳过自己的内容；进入后确认不是错误页，能识别标题/作者并能看到互动信息。不要对同一失效链接盲目重试，返回结果页换下一条。

## 爆款改写

先记录标题、封面层级、正文结构、互动机制和标签，再输出全新文案。默认只借鉴风格与结构，不复用原图、原句、专属信息或隐私；不承诺必爆。
