# AI短剧研发全量评估体系 V12.3

本模块用于对AI短剧剧本进行工业化、可复现的质量评估，覆盖从钩子到连载留存的完整维度。

## 评估体系文档

完整评估标准文档：`AI_short_drama_eval_system_V12.3.md`（位于content-creator-expert根目录）

评估前必须完整阅读该文档，严格按照其中的规则、阈值、公式执行。

## 核心评估维度

### 1. 抽样窗口（必查）
- **Ep1-Ep3**：钩子、规则确立、前三集工艺
- **付费点窗口**：第10-15集选1集
- **临近结局**：倒数3-5集选1集

### 2. 必查硬指标
- **DW-90二段式**：15s答题（目标/阻碍/代价）+ 90s首次交付（R类/P类）
- **U-Scan理解成本**：U1-U6理解税校验
- **Hard Gates**：合规闸门(C0/C1/C2)、逻辑闸门、成本闸门
- **ARG投放可用性**：可截屏风险、高敏组合镜头
- **PCG前三集工艺**：文本糙度、镜头可执行度

### 3. 五维评分（0-100）
- **SPS（内容价值）**：爽点密度与质量，6分及格线（每90s至少1个可剪爽点）
- **CAP（性格力）**：人物公理、反差标签、动机稳定性
- **B+3（硬骨架）**：交付达标、因果台阶、兑现强度、闭环密度
- **APM（叙事动能）**：压强频率、升级链、反转质量
- **VIS（视觉张力）**：建模潜力、特效溢价、形变可控性
- **Type D追加：IV（信息位移）**：资产化位移、来源追溯、钩子密度

### 4. SGM核爆指标（爽点质量制衡）
- **IAI信息差势能**：全知碾压/绝境盲盒/认知同频
- **SCPR社会资本剥夺率**：杀人诛心/物理降维/隔靴搔痒
- **ELR情绪杠杆率**：核爆杠杆/线性对冲/疲劳通胀

### 5. Phase L连载风险（前10集）
- L1外部主线倒计时
- L2落锤密度
- L3持续对抗者
- L4场景同构疲劳
- L5剧情连通率（Russian Doll Protocol，禁止主线完全闭环）
- L6悬疑清晰度（仅悬疑分支）

## 执行流程

1. 用户提供剧本（大纲+前几集正文）
2. 读取完整评估体系文档 `AI_short_drama_eval_system_V12.3.md`
3. 确定Type路由（Type A/B/C/D）
4. 按抽样窗口逐集检查，绑定证据坐标
5. 计算各维度得分，应用Gate/Cap/Deduction规则
6. 合成P-Score和R-Score，给出Verdict
7. 输结构化评估报告和改稿任务单

## 重要红线

- **无证据不判定**：所有问题必须绑定`[集数-行号]`或`[集数-场景-台词]`坐标
- **SPS守恒原则**：任何约束若导致爽点密度下降必须回收爽感，SPS<6默认Reject
- **K（熔断）> 加权分 > Cap**：闸门规则优先于得分
- **审美分歧不决定Pass/Reject**：仅证据/阈值/风控类问题判定生死
