# AI营销视频生成模块

基于即梦大模型的营销视频创作工具，专注于产品展示、品牌宣传、广告短片等营销场景视频生成。

## 功能模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 文生视频(T2V) | 文字描述直接生成视频 | 创意概念视频、产品展示 |
| 图生视频(I2V) | 以图片为首帧生成动态视频 | 产品海报动态化、照片动起来 |
| 首尾帧控制(FLF) | 指定开头和结尾画面生成过渡 | 产品变形、场景转换 |
| 视频续写(V2V) | 在现有视频基础上继续生成后续内容 | 延长视频时长、故事续接 |

## API配置（必须）

使用前需要配置NewAPI环境变量：

```bash
# 添加到 ~/.zshrc
export NEWAPI_BASE_URL="你的API服务地址"
export NEWAPI_API_KEY="你的API密钥"
```

配置完成后运行：
```bash
node api/scripts/configure.js
```

## 创作流程

### 1. 需求澄清
先明确以下要素：
- **视频主题**：产品展示/品牌宣传/活动预告/概念创意
- **时长**：3秒/5秒/10秒（根据场景选择）
- **比例**：16:9横屏/9:16竖屏/1:1方形
- **风格**：写实/科技/清新/复古/动漫等
- **画面内容**：主体、场景、动作、氛围

### 2. Prompt编写规范

好的视频prompt结构：
```
[主体描述] + [动作/运动] + [场景环境] + [镜头语言] + [光线/色彩] + [风格质感]
```

示例：
```
一款银色智能手机放在白色大理石桌面上，镜头缓慢推进，手机屏幕亮起显示APP界面，
柔和的侧光照明，干净明亮的现代简约风格，8K高清质感
```

### 3. 镜头语言参考

常用运镜方式：
- **推镜（Push In）**：镜头向主体靠近，突出重点
- **拉镜（Pull Out）**：镜头远离主体，展示环境
- **平移（Pan）**：镜头水平移动，展示全景
- **环绕（Orbit）**：镜头围绕主体旋转，360度展示
- **跟随（Follow）**：镜头跟随主体运动
- **升降（Crane Up/Down）**：镜头垂直移动，大场景展示
- **手持（Handheld）**：轻微晃动，真实感/临场感

常用景别：
- **特写**：突出细节（产品纹理、表情）
- **近景**：胸部以上，人物表情/产品主体
- **中景**：膝盖以上，人物动作/交互
- **全景**：人物全身+环境
- **远景**：大场景，氛围渲染

### 4. 营销视频常用模板

**产品展示类：**
```
[产品名称]放置在[背景]上，[镜头运动]展示产品外观，
[光线描述]打亮产品轮廓，[质感描述]材质细节清晰可见，
整体风格[风格关键词]
```

**品牌宣传类：**
```
[场景描述]，[人物/主体动作]，氛围[氛围关键词]，
色彩[色调描述]，传递[品牌调性]感觉，
镜头[运镜方式]，电影级质感
```

**活动预告类：**
```
[活动元素]动态出现，[特效描述]，文字"[活动主题]"，
节奏[节奏描述]，色彩[主色调]，充满活力感
```

### 5. 输出与调用

Prompt编写完成后，使用API调用生成视频：

```bash
node api/scripts/invoke.js --type video \
  --prompt "你的视频描述prompt" \
  --model "jimeng-2.0" \
  --duration 5 \
  --ratio "16:9"
```

参数说明：
- `--prompt`: 视频描述文本（必需）
- `--model`: 模型版本，默认jimeng-2.0
- `--duration`: 视频时长（秒），支持3/5/10
- `--ratio`: 画面比例，16:9/9:16/1:1
- `--first-frame`: 首帧图片路径（图生视频模式）
- `--last-frame`: 尾帧图片路径（首尾帧模式）

### 6. 内容合规要求

⚠️ 创作视频时必须遵守：
- 不生成涉及真实公众人物、名人 likeness 的内容
- 不生成侵犯他人知识产权的内容
- 不生成暴力、色情、政治敏感等违规内容
- 不生成虚假宣传、误导消费者的内容
- 营销内容需符合广告法相关规定
- 使用原创或已获授权的素材作为参考
