## 2. 评审输入规范：Dynamic Window（必抽样）
### 2.1 DW-90 二段式核查（新增｜每个抽样集必查）
- **15s 内答题**：观众必须知道（目标 / 阻碍 / 失败代价）
- **90s 内首次交付**：二选一即可
  - **R类（Rule Proof）**：规则证据化交付（展示规则样本/后果/契约条款/UI判定）
  - **P类（Payoff）**：成果型交付（能力/证据/资产/地位 之一到账）

> 允许“铺垫型集”用 R 类交付达标；不允许 90s 内“只有解释、无交付”。

> 目的：保证不同评审员看同样的窗口，结论可比。

**必须抽样集（最低配置）**
1. **Ep1**（钩子与规则确立）
2. **Ep2**
3. **Ep3**
4. **付费点窗口**：第 10–15 集中选择 1 集（或你们内部定义的“付费点”）
5. **临近结局窗口**：倒数 3–5 集选择 1 集

**Ep1 的 4 个强制检查点**
- 3 秒钩子
- 15 秒答题（观众知道“为什么要看下去”）
- 60 秒冲突树（至少 2 条压强线并行）
- 结尾钩子（下集必看理由）

### 2.1.1 U-Scan 理解成本核查（新增｜以“可复述”为准）

> 核心原则：短剧所有表达（台词/行为/画面）都必须服务于 **“让用户理解故事进展”**。

**U1｜15秒三问复述（硬）**
- 评审员在 15s 窗口结束后，必须能用一句话复述：
  1) 主角此刻要什么（目标）
  2) 谁/什么在阻止（阻碍）
  3) 失败会怎样（代价）
- 允许悬疑的“已知未知”：当 `TypeB_Genre==SUSPENSE` 时，允许 **真凶/动机/作案方法**暂未知；但不允许“发生了什么/在追什么/风险是什么”未知。

**U2｜90秒结果句（硬）**
- 评审员在 90s 窗口结束后，必须能写出“结果句”（可复述的进展交付），并绑定证据坐标。
- `TypeB_Genre==NON_SUSPENSE` 的等价交付：
  - R类：规则证据化（条款/UI判定/样本后果）
  - P类：成果到账（能力/证据/资产/地位）
- `TypeB_Genre==SUSPENSE` 的等价交付（任一类即可 PASS）：
  - **线索交付**：拿到关键证据/口供/反常点
  - **排除/锁定**：排除一名嫌疑/锁定范围/确定作案窗口
  - **危机升级**：小案结算但触发更大案/更深层对手（与 L5 套娃连通一致）
  - **不可逆代价**：做了就回不了头（立案/曝光/被盯上/证据被毁等）

**U3｜显性信息载体（软｜防“能懂但太费劲”）**
- 每个关键场景必须至少命中 1 类“显性信息载体”：
  - 台词（可口型、可复述的明确句）
  - 可读 UI/文字（金额/条款/聊天/诊断/转账/判定等）
  - 明确行为结果（不靠猜：例如“转账成功提示/封条贴上/警报与倒计时”等）
- 若三者都没有 → 记为“高理解成本场景”，进入扣罚/封顶（见 6.5）。

**U4｜静默场景协议（白名单）**
- 允许静默/纯镜头语言，但必须：

#### U6｜System Simplicity（金手指极简法则｜V12.2 新增｜硬约束）

> 目的：解决“系统混乱/开篇逻辑不合理”导致的理解税与留存崩塌；把系统从“说明书”降维为“可复述、可投放、可结算”。

**适用范围（强制）**：出现以下任一元素即启用 U6：`系统/面板/数值/抽卡/国运/商城/技能树/天赋点/概率池/倍率/加权/波动系数`。

**判定窗口（硬窗口）**：前 **5 集**必须完成“极简可用”的系统交付。

**FAIL 条件（触发任一即 FAIL）**：
1) **条件语句层级 > 2 层**
   - 单层：`杀敌 → 得积分 → 换武器`
   - 双层：`杀敌 → 得积分 → 积分受等级影响 → 换武器`（仍可接受）
   - **>2层（直接 FAIL）**：`杀敌 → 得积分 → 国运波动相乘 → 进盲盒池抽奖 → 再折算武器`
2) 同一集内出现 **≥2 次**“换算/乘除/加权/概率池/倍率解释”。
3) 解释未绑定“立刻到账”：解释后 **60 秒内**无明确收益交付（R 类证据化 / P 类成果到账任一）。

**触发动作（统一执行）**：
- `risk_tags += ["U6_system_complexity"]`

- **R-Score 上调 1 档**（需要改写系统呈现方式）
- **Verdict 上限封顶**：`Pass → Revise`（除非同时命中 SGM 核爆且 ARG/PCG 全绿，才允许“带条件 Pass”）

**强制改稿动作（派单口径）**：删减数值换算与叠层条件，改为 **1句人话规则 + 1个 UI 提示 + 1个立刻生效的结果镜头**。

**输出字段（必填）**：`U6_System_Simplicity = PASS/FAIL`；`U6_layers = 1/2/3+`；`U6_evidence=[...]`。

- 落锤定义：单集内出现事实/权力/身份/资源/规则/舆论/法律结果的**落地变化**（不是吵架）。

- 判定：对抗方是否持续施压、是否存在升级路径、主角是否持续付代价。

  - Type A：同构≥3次且无增量=红

### L5 剧情连通率（Plot Connectivity｜Russian Doll Protocol｜V12.1）

**红线规则（主线危机层）：**
- IF(当前案件解决 == 主线危机彻底解除) → **L5=RED（FAIL）**
- IF(当前案件解决 == 触发更大危机的导火索) → **L5=PASS**
- IF(当前案件解决 == 暂时缓解但引入更硬约束/更强对手/更高代价) → **L5=PASS**

**强制执行（评审动作，不是口号）：**
1) **因果链图（必须画/必须写）**：列出 Ep1–Ep10 的“事件→后果→更大危机”链条（可用文本树/表格/简图）。  
2) **删集测试（必做）**：对任意一集（优先 Ep4/5/6）回答：  
   - “删掉这一集的案件，Ep10 的结局是否必须改？”  
   - 若回答“否”，或只能给出“情绪更弱”但主线不变 → 判定为 **连通弱/水剧情**（L5 至少 YELLOW，严重则 RED）。

**V11.8 补丁：结算窗口期（Settlement Window, SW）与纯净度法则（防“焦虑跑步机”）**

> 允许“短暂的完全胜利”，让观众完成多巴胺结算；**结算必须纯净**，新危机必须“窗口后播种”。

- **悬疑题材适配**：若题材为悬疑/推理，SW 允许以“关键线索证据化 / 认知翻转落地 / 误导拆穿”作为结算，不强制必须‘打败反派’或‘拿到战利品’。
- **纯净度要求**：窗口内 **禁止**引入新的主线危机（可埋伏笔，但不得打断爽感）。

**V12.1 补丁：L5-A 有效推进扩容法则（Valid Progression Expansion）**

> **目的**：承认“关系、秩序、认知”的不可逆改变，本身就具有与“更大危机/更强对手”同等甚至更高的商业留存价值。  
> 当单集/单元没有显性触发“更大危机”，但达成以下任意一项 **不可逆的实质性改变**，同样视为 **PASS（有效推进）**，免除水剧情警告。

**任一项满足即可视为 PASS**
1. **关系不可逆推进（Relationship Shift）**  
   核心人物之间的敌友阵营、情感羁绊、信任结构发生实质且不可逆的改变。  
   例：死敌转为暗中盟友、主角获得关键人物的性命托付、伴侣/盟友完成站队不可逆。
2. **秩序/规则重定义（Order Redefinition）**  
   主角在当前生态位中获得新的合法性、阵营支持，或直接夺取某项规则的 **解释权/执行权/裁定权**。  
   例：从“被审判者”转为“制定规则的人”、从边缘者获得公开背书与秩序位置。
3. **认知升级（Cognitive Paradigm Shift）**  
   悬疑线索完成决定性归位，核心误导被彻底拆穿，或世界观底层规则被推翻重写。  
   例：真相链重组、关键误会彻底解除、观众与主角的认知站位发生跃迁。

**注意（不得滥用）**
- 只是一时态度缓和、表面和解、轻微增量，不构成 PASS；
- 若所谓“关系推进/认知升级”无法改变后续决策链与人物站位，只能记为情绪变化，不算有效推进；
- 仍需绑定证据坐标，且建议通过“删集测试”验证：删掉该集后，后续人际结构/秩序结构/认知结构是否必须改写。

**输出字段（建议补充）**
- `L5A_valid_progress_type`（RelationshipShift / OrderRedefinition / CognitiveShift / None）
- `L5A_evidence[]`
- `L5A_delete_test_result`（MustRewrite / WeakImpact / NoImpact）

- **判定标签（枚举）**：
  - 🔴 **核爆杠杆（High Leverage｜20分）**：极短铺垫即可形成具象切肤之痛（支点），随后出现毁灭性释放（爆点），观众“瞬间回血”。
  - 🟡 **线性对冲（Linear Leverage｜10分）**：压迫与反击篇幅对等，常规你来我往，尚可。
  - ⚫ **疲劳通胀（Emotional Inflation｜0分｜扣分项）**：铺垫过长/太憋屈，或反击过软，观众情绪在等待中破产。
- **证据绑定（必填）**：`SGM_ELR_Label` + `SGM_ELR_Fulcrum_Coords[]`（支点）+ `SGM_ELR_Blast_Coords[]`（爆点），各至少1处。

#### 5.7.4 计算与制衡规则（工业口径）
- **SGM 得分（0–10）**：  
  `SGM_Score_0_10 = round((IAI_pts + SCPR_pts + ELR_pts) / 6, 0)`  
  其中 `IAI_pts/SCPR_pts/ELR_pts ∈ {0,10,20}`（按上述标签映射）。
- **制衡逻辑（对冲“爽点密度=无脑打脸”）**：
  - 若 `SPS_Score_0_10 ≥ 6` 但 `SGM_Score_0_10 ≤ 3` → 判定为 **“爽点低质/隔靴搔痒”**：等级最高封顶 **B**，且进入 **Revise**（要求补足至少一处“资本剥夺”或“认知崩塌”高质量爽点）。
  - 若 `SCPR = ⚫` 且题材路由为 **复仇/权谋/鉴渣/职场清算**（非悬疑主打）→ **必须 Revise**（补“社会资本剥夺”），否则即便爽点密度足也视为“只会吵架”。
- **悬疑分支豁免（避免限制悬疑题材）**：
  - 悬疑/推理路由允许 `IAI = 🟡 绝境盲盒` 作为满分形态（不强制全知碾压）。
  - 悬疑前3集允许 `SCPR` 暂为 🟡/⚫（反派尚未被诛心），但 **必须在前10集内至少出现1次 SCPR=🔴 或 2次 🟡**；否则判定“悬疑无反击结算”，进入 Revise。

#### 5.7.5 评审最小动作（防主观）
评审员/AI 只需要做三件事：
1) 选标签：`IAI/SCPR/ELR` 各选一档；  
2) 绑坐标：每项至少1个证据坐标（ELR 需支点+爆点）；  
3) 给出一句话解释（≤20字）：**“认知崩塌点/资本剥夺点/杠杆支点-爆点是什么”**。

## 7.5 一致性与商业落地校验层（V12.2 新增｜用于人审/AI 对齐）

### RCC｜Rule Coherence Check（规则一致性检测｜硬）

> 目的：补齐 U1/U2 之外的“因果闭环与系统四要素”验证，专治：系统混乱、开篇逻辑不合理、世界观前后矛盾。

- **RCC-1 15 秒复述一致性（硬）**：不同评审员对“主角是谁/处境是什么/立刻要赢什么”的一句话复述若显著不一致 → 标记理解税风险。
- **RCC-2 90 秒因果闭环（硬）**：90 秒内的结果交付必须能追溯到明确动作或规则；不得“凭空发生/作者强行给”。
- **RCC-3 系统四要素（硬）**：系统/金手指必须满足四要素中至少三项清晰：**触发条件 / 代价 / 收益 / 限制（冷却/次数/场景闸/反噬）**；缺失=标记“系统混乱”。

**触发动作**：`risk_tags += ["RCC_incoherent"]`；**FinalScore -= 5 或 Verdict 上限封顶为 Revise（实现二选一）**。

### 结论输出升级：P-Score + R-Score（二维｜硬口径）

> 目的：把“内容高分但修不动/投不出去”的项目从高优先级区剔除，提升立项 ROI。

- **P-Score（潜力）**：核爆潜力、题材匹配、爽点质量（含 SGM）
- **R-Score（可修复成本）**：合规降噪成本、系统重写成本、前三集工艺返工成本、视觉同构返工成本

**推荐决策（统一口径）**：
- `P高 + R低` → 推荐立项（Pass）
- `P高 + R高` → 修改后立项（Revise）
- `P低 + R高` → 不推荐立项（Reject）
- `P低 + R低` → 备选（看产能与档期）

### 分歧归因字典（D1–D4｜用于“人工 vs AI”复核）

- **D1 证据分歧**：坐标、计数、抽样窗口错误

### 6.13 Process Dump 唯一扣罚（V12.0 继承｜V12.1 保留｜分级扣罚）

> 定义：由 U5 检测得到的 `ProcessDump_Count`。U5 **只记录**，此处为 **唯一扣分入口**（防重复惩罚）。

- **触发**：`ProcessDump_Count > 0`
- **执行（分级扣罚）：**
  - `ProcessDump_Count == 1`：  
    - `FinalScore -= 3`  
    - `SPS -= 1`
  - `ProcessDump_Count >= 2`：  
    - `FinalScore -= 6`  
    - `SPS -= 2`

- **修复原则（不增加额外扣分，仅规定改稿动作）：**
  - 用 **“结果前置 + 一句话人话 + 证据化载体”** 替换流程/术语堆叠
  - 让“专业动作”转为 **Job Highlight 三要素**（结果句/载体/局势改变）

### 6.13A 高级感豁免协议（Prestige Exemption｜V12.1 新增）

> **目的**：区分“无效说明书式解释”与“高价值的权力仪式感/制度威压/认知碾压”，避免 Process Dump 误伤高阶逼格。  
> **适用范围**：仅当 U5 检测到某场景存在 **连续 ≥3 句**术语/流程/规则陈述时，才进入本条款判定。

**豁免条件（满足任意两项 → 不计入 `ProcessDump_Count`）**
1. **权力与制度威压（Power/Institutional Pressure）**  
   该段落明确承担了 **身份压迫 / 权力审判 / 高位者绝对解释权建立** 的叙事功能，而非单纯说明规则。
2. **延时闭环交付（Delayed Closure Delivery）**  
   该场景虽未在当下立刻落锤，但在 **同场景末尾** 或 **紧接的下一拍（Next Scene）**，完成了符合 U2 标准的 **“结果句 + 证据化载体”**。
3. **服务高阶核爆指标（Serves SGM）**  
   该解释性段落直接且必要地服务于本集/本单元的 **SGM 高分项**（如：促成 IAI 的“全知碾压”、SCPR 的“杀人诛心”、ELR 的“核爆杠杆”）。

**排除（不得豁免）**
- 只是术语堆叠、流程教学、世界观说明，而**没有**形成权力压迫/结果落锤/SGM 爆点；
- 以“高级感”为名，实则拖慢节奏、抬高理解成本、且无法在下一拍完成闭环；
- 需要额外旁白解释才能成立，或无法绑定证据坐标。

**输出字段（建议补充）**
- `Prestige_Exemption_Triggered`（Y/N）
- `Prestige_Exemption_Reasons[]`（PowerPressure / DelayedClosure / ServesSGM）

### 6.14 SGM（社会心理矩阵）封顶与路由联动（新增）

> **目的**：把“爽点质量”写成可执行的工业规则，避免只靠 `SPS_ClippableHits` 计数导致无脑打脸。

- **触发字段**：`SGM_IAI_Label / SGM_SCPR_Label / SGM_ELR_Label / SGM_Score_0_10`
- **封顶规则（Hard Cap）**：
  1. 若 `SPS_Score_0_10 ≥ 6` 且 `SGM_Score_0_10 ≤ 3` → **Grade Cap = B**，并强制 `Final_Decision = Revise`（补“认知崩塌/资本剥夺/杠杆爆点”其一到位）。
  2. 若路由为 **复仇/权谋/鉴渣/职场清算** 且 `SGM_SCPR_Label = ⚫` → **必 Revise**；若在前10集仍无法实现 ≥🟡 的资本剥夺，则 **Reject**（爽点“无社会代价”不可售）。
- **悬疑分支豁免（Anti-Punish for Mystery）**：
  - 悬疑/推理可将 `IAI = 🟡 绝境盲盒` 视为满分形态；`SCPR` 可延迟结算，但前10集必须满足：`SCPR=🔴` 至少1次或 `SCPR=🟡` 至少2次，否则进入 Revise。

## 11. 复评与质检（V11.8｜Reject / Revise / Seed｜分级诊疗）

> 目标：不漏掉好苗子，不浪费算力在垃圾上；让“爽感”成为可量化的工程指标，而不是评审员的主观刑场。

### 11.1 Fast Pass（初筛｜5–10 分钟/部）

**执行者**：初级评审 / AI  
**输入**：抽样集（至少 Ep1–Ep3 + 付费窗 1 集）

**检查项（4 项必查）：**
1. `Router_Quick`：Type A/B/C/D + ACF 二值判定（≥60 / <60）。**若 <60 → Reject**。
2. `SPS_Check`：输出 `SPS_Score_0_10` 与 `SPS_ClippableHits_0_180s`。  
   - `SPS_Score_0_10 < 6` → 默认 Reject（除非明确可在不改结构的前提下拉回 ≥6）。
3. `Hard Gates`：合规/OOC/硬逻辑矛盾等 P0 红线（命中任一 → Reject）。
4. `DW-90`：15s 答题 + 90s 首次交付（任一 Fail 进入“是否可 Revise”判定）。

**输出结论（三态）：**
- 🔴 **Reject（淘汰）**：Hard Gate 挂科 / ACF < 60 / `SPS_Score_0_10 < 6` 且不可修复 / 结构型坍塌（无法写出可交付结果句）。
- 🟡 **Revise（重修）**：仅限 **表达型/节奏型**失误（结构仍成立，SPS 机制明确）。
  - **准入示例**：15s 三问能答清，但 90s 交付缺 1 个“结果句/证据镜头”；或爽点位置错位导致 SPS 被稀释。
- 🟢 **Seed（种子）**：全 Pass，进入 Deep Scan 精修池。

> **硬闸**：结构型问题（主线危机不存在/动机闭环不成立/核心反派不可落地/10 集内没有连载推高机制）不得进入 Revise，直接 Reject。

### 11.2 Deep Scan（精修｜30 分钟+/部｜仅 Seed）

**执行者**：资深评审 / 责编 / AI Pro  
**输出**：全量字段 + Must Fix 清单 + 归因到 Gate/Cap/Deduction

**检查项（全量武器库）：**
1. **U-Scan**：理解成本、静默协议、术语落地与 `ProcessDump_Count`（扣分只走 6.13）。
2. **Phase L（L-Scan）**：L1–L6 全量；重点复核 **L5 套娃连通 + SW 结算窗口纯净度/频率**（Ep3 起算）。
3. **Job Highlight**：三要素（结果句/证据载体/局势改变）与 ACF_B_1 ≥14 的达标性。
4. **PSD Gate**：成年人动机闭环（Profit/Survival/Irreversible-Cost Driven）。
5. **SGM-Scan（社会心理学博弈矩阵｜P0）**：对 **IAI/SCPR/ELR** 三项打标并绑定坐标（认知崩塌/资本剥夺/支点-爆点），用 `SGM_Score_0_10` 触发 **6.14 封顶与路由联动**（防止“爽点高但隔靴搔痒”）。
6. **红队/雷达双模（必跑，结果必须落地到条款与改稿任务）：**
   - **Red Teaming（对手模式）**：专门找“现实世界必死点/反派不合逻辑点/降智点/职业听不懂点”。
   - **Market Radar（雷达模式）**：验证爽点不过期、人设在审美窗口内、话术可二创。

### 11.3 复评一致性与质检（保留 V11.6.1）

- **双评审独立打分**（对 Seed 项目强制）。
- 触发复评条件：总分差 **> 8**，或任一维差 **> 15**。
- 第三人复评只允许做两件事：
  1) 证据坐标是否成立

### 11.4 AI 置信度信号路由协议（V12.0 继承｜V12.1 保留）

> 适用：**AI 自动化初筛** / **人机共驾**。  
> 核心：AI 不做裁决，只做 **可审计信号提取**；路由仅决定“是否人工抽检信号”，不等于最终 `Decision`。

#### 11.4.1 信号输出（必须三路齐全）

AI 必须为每个抽样集输出三路信号（并分别给出 0–100 的整数置信度）：

1. **SPS_Signal**
   - 必填：`Hit_Exist`、`Hit_Type`、`Result_Sentence`、`Evidence_Coords`、`Conf_SPSHit`
2. **DW90_Signal**
   - 必填：`Result_Sentence`、`Evidence_Coords`、`Conf_DW90_ResultSentence`
3. **ProcessDump_Signal（异构口径）**
   - 必填：`Dump_Exist`、`Count`、`Conf_ProcessDump`
   - 若 `Dump_Exist=Yes`：额外必填 `Evidence_Coords`
   - 若 `Dump_Exist=No`：`Evidence_Coords` 可为空（避免强迫编造）

> **硬护栏（证据绑定）**：任一路信号缺其必填项 → 本次 AI 输出视为 **无效**，直接路由 **Abstain**（交人类专家完整裁决），不得进入 Suspect。

#### 11.4.2 Conf_Min 公式（禁止脑补）

- **公式**：`Conf_Min = min(Conf_SPSHit, Conf_DW90_ResultSentence, Conf_ProcessDump)`

#### 11.4.3 路由阈值（信号免检级别）

前提：**证据齐全**（见 11.4.1 硬护栏）。

- 🟢 **AutoPass（人工免检）**：`Conf_Min >= 90`
- 🟡 **Suspect（人工抽检）**：`70 <= Conf_Min < 90`
- 🔴 **Abstain（弃权/熔断）**：`Conf_Min < 70` 或 **证据不齐**

> **注意（关键工程口径）**：  
> - `AutoPass` 仅表示 **AI 的三路信号无需人工抽检**。  
> - **无论 Router_Status 为何，规则引擎都必须执行**：Hard Gates、ACF、Revise_Feasibility，并合成最终 `Final_Decision = Reject / Revise / Seed`。  
> - AI 不得“越权”跳过 Hard Gate（避免“高分违规”自动过）。

#### 11.4.4 人工抽检范围（只查存疑信号）

- Suspect 的人工抽检只核查：`Conf_Min` 对应的 **短板信号**（SPS/DW90/Dump 其中之一），避免人类重新完整读剧本导致抽检池爆炸。
- Abstain 则由人类专家 **完整裁决**（包含 Hard Gate 与结构判断）。

#### 11.4.5 反作弊校准：Overconfidence Strike（仅客观事实）

> 目的：压制“盲目自信”，并防止 AI 用简单样本刷分恢复 AutoPass。

- **触发**：当 `AutoPass` 样本被人工复核推翻，且属于**客观事实错误**（满足任一）：
  1) `Evidence_Coords` 不存在/不对应结果  
  2) `Hit_Exist/Hit_Type` 无中生有  
  3) `DW90 Result_Sentence` 非 90s 内交付  
  4) `ProcessDump Count` 计数错误或 Dump 误判  
- **不触发**：审美争议（如“爽点不够爆/情绪不够强”）、风格偏好、主观口味差异。
- **惩罚**：累计 **3 次 Strike** → 该模型/Prompt 的置信度上限强制设为 **89%**（失去 AutoPass 权限，全部转 Suspect/Abstain 路由）。
- **恢复条件（防样本偏差）**：
  1) 连续 **50 单**人工复核正确率 **> 95%**  
  2) 且这 50 单中 **Suspect/Abstain 复杂样本占比 ≥ 30%**

## 附录C：V12.1 执行口径与最小判例框架（新增）

> **目的**：降低 6.13A 与 L5-A 的执行漂移，避免 AI/人工评审对“逼格豁免”与“有效推进”口径不一。  
> 本附录不是新增评分模块，而是**统一口径**的最小说明。

### C1. 6.13A Prestige Exemption 最小判例

**可豁免（正例方向）**
- 高位者用 3–5 句制度术语完成“身份压迫/解释权垄断”，并在同场末尾拿出契约、印玺、回执、录音等完成结果锁死。
- 权谋审讯中，术语陈述本身就是“制度威压”的武器，并直接服务于 IAI/SCPR 爆点。
- 看似解释，实则是为下一拍的证据反杀/社会审判埋刀。

**不可豁免（反例方向）**
- 连续讲设定、讲流程、讲历史，但不改变任何人的局势；
- 术语很多，但观众只能知道“这个人很懂”，不知道“发生了什么结果”；
- 只能靠旁白补课或幕后注释才能成立。

### C2. L5-A 有效推进扩容 最小判例

**可视为 PASS（正例方向）**
- 核心死敌转为暗线盟友，后续阵营版图必须改写；
- 主角拿到公开背书/继承权/裁决权，秩序位置不可逆改变；
- 悬疑误导链被拆穿，观众与主角对真相的认知站位发生根本跃迁。

**不可视为 PASS（反例方向）**
- 只是态度缓和、嘴上讲和、下集又回到原位；
- 只是补了一条线索，但不会改变后续判断链；
- 只是角色更喜欢彼此了，但既不改变阵营也不改变决策。

### C3. 执行建议
- **Fast Pass 不增加字段负担**：6.13A 与 L5-A 默认只在 **Seed/Deep Scan** 中启用。
- **优先证据化**：所有豁免/有效推进必须绑定坐标，不能空判。
- **必要时走对手模式**：若评审员对“这是逼格还是Dump”“这是推进还是水剧情”拿不准，优先用 Red Team 提问法拆解其是否改变局势/结构/认知。
