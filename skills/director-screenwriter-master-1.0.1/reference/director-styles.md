# 模式5：导演风格库（9 种｜创作时先选风格）

> 用法：创作/改写/评估前确定主风格；每种风格给出**视觉语法 / 节奏参数 / 声音设计 / 表演指导 / 适配题材 / 体系联动 / 踩雷提示**。
> 风格不是装饰：风格决定"每 90 秒爽点的呈现形态"，直接影响 SPS 可剪性、VIS 评分、U4 静默协议与 ARG 截屏风险。

## 1. 卡点爽感流（Beat-Punch Flow）

- **一句话定位**：每 3–5 秒一个可剪爆点，BGM 强卡点，打脸/翻盘如鼓点连击。
- **视觉语法**：中近景为主；快速正反打；落锤瞬间推镜/定格/闪白；金句配大字 UI 弹幕式呈现。
- **节奏参数**：镜头均长 1.5–3s；每 90s ≥2 个可剪爽点；落锤卡点精确到帧。
- **声音设计**：BGM 全程驱动，鼓点/音效与动作同步；爽点处"爽音效 + 静帧 + 回响"。
- **表演指导**：外部动作大于内心戏；反应镜头（瞳孔地震/嘴角上扬）是标配。
- **适配**：男频逆袭/复仇打脸/系统流/规则奇观（Type A/B）。
- **体系联动**：SPS 高分项；SGM 必须绑定"认知崩塌/社会性死亡"落点，否则沦为"无脑打脸"（SGM ≤3 → 封顶 B + Revise）；注意 VIS_Diversity：卡点同构（同武器/同特效/同景别连续 4 次）会触发同质化扣罚。
- **踩雷提示**：爽点无社会代价（SCPR=⚫隔靴搔痒）→ 必 Revise；单集无 SW 结算窗口连续 ≥5 集 → 红牌。

## 2. 视听奇观流（Spectacle Flow）

- **一句话定位**：大场面/特效/动作调度是叙事主体，视觉本身就是爽点。
- **视觉语法**：大全景开场立世界观；动态运镜（环绕/升降/追拍）；特效色域统一；怪物/道具辨识度优先。
- **节奏参数**：奇观段 10–20s 一场；战斗可拆镜头（起手/中段/结算三拍）；每 3 集至少 1 次奇观级视觉高潮。
- **声音设计**：低频轰鸣 + 史诗 BGM；结算瞬间静音一拍再爆。
- **表演指导**：体态与调度大于表情；主角动作线清晰（谁打谁、怎么赢一目了然）。
- **适配**：玄幻/修真/末世/机甲/怪兽（Type A）。
- **体系联动**：VIS 权重最高（Type A 权重 0.35）；形变压力必须可代偿/可简化（DCF 成本 Gate）；强制 VIS_Diversity 异构（第 4 次破局换武器/换景别/换结算逻辑）。
- **踩雷提示**：特效堆叠但信息增量≈0 → L4 同构红；UI 遮脸（Type A 也应遵守）≥2 次/集 → -10。

## 3. 悬疑压迫流（Suspense Flow）

- **一句话定位**：暗调低机位，压迫感通过镜头密度与信息错位制造。
- **视觉语法**：低角度/过肩镜；阴影分割画面；线索特写（物证/字条/监控）必须给足停留时间；误导镜头与真相镜头同构呼应。
- **节奏参数**：镜头略长（3–6s）制造压抑；每集 ≥1 条可复述线索 + 1 个新问题（M-Scan 硬要求）；反转点用 0.5s 闪回串联。
- **声音设计**：低频悬疑 pad + 心跳音效；线索出现时"提示音 + 焦点收缩"。
- **表演指导**：微表情主导；隐瞒者与知情者的视线差（谁先移开目光）。
- **适配**：悬疑/轻悬疑/案中案/翻案链（Type B 悬疑分支）。
- **体系联动**：L6 M-Scan 必跑（线索/新问题/隐瞒责任归属）；U2 悬疑等价交付（线索/排除/锁定/升级/不可逆代价）；静默场景（U4）可用但 ≤6s 且必须承载线索交付。
- **踩雷提示**：只有悬念无线索 → 连续 2 集 M1 缺失 = L6 红；"作者未交代的空白" = L6 黄；烧脑但看不懂 → U1/U2 FAIL。

## 4. 情绪共振流（Emotional Flow）

- **一句话定位**：慢镜特写留白，情感浓度通过"支点-爆点"杠杆引爆。
- **视觉语法**：特写占 40%+（眼睛/手/细微表情）；柔光/逆光；空镜留白承接情绪；回忆闪回用色调区分。
- **节奏参数**：情感戏镜头 4–8s；每集 ≥1 次"情绪支点"（屈辱/心碎/守护）+ ≥1 次"情绪爆点"（站队/拥抱/公开宣示）；SW 结算窗口拉满 60s。
- **声音设计**：钢琴/弦乐主导；静音+环境音（雨/呼吸）做情绪重锤。
- **表演指导**：内敛优先，反应镜头给足；亲密互动遵守肢体分级（≤2s 接触直接给，2–5s 必须遮蔽代偿镜头）。
- **适配**：女频婚恋/家庭伦理/真假千金/双向奔赴（Type B）。
- **体系联动**：RRL 关系台阶必做（公开站队/共担代价/共享秘密 3 级）；SGM ELR 核爆杠杆（支点短→爆点狠）；SW 纯净度（禁止情绪戏中插入新危机）。
- **踩雷提示**：态度瞬变无台阶 → RRL FAIL；"虐"无代价闭环 → PSD FAIL（为虐而虐）；支点过长 → ELR 疲劳通胀 0 分。

## 5. 权谋克制流（Prestige Flow）

- **一句话定位**：对称构图仪式感，制度威压本身就是戏；克制即高级。
- **视觉语法**：对称构图/固定机位/俯视全景压人；服饰/道具/空间等级分明；镜头移动极慢或不动，靠调度内变化。
- **节奏参数**：台词戏长镜头（6–10s）；每场戏必须有"局势改变"落点（不能只有嘴炮）；仪式/宣判/递契等动作放慢给足。
- **声音设计**：环境声大于配乐；钟/鼓/盖章等制度音效重复出现形成记忆锚。
- **表演指导**：端住仪态，情绪收在眼神；高位者不吼，用"停顿+一个词"压人。
- **适配**：权谋/古装/家族/职场高位博弈/制度戏（Type B）。
- **体系联动**：6.13A 高级感豁免直接保护此风格（连续术语若承担"权力/制度威压 + 延时闭环交付" → 不计 Process Dump）；但每场术语戏必须"同场景末尾或下一拍完成结果句 + 证据载体"。
- **踩雷提示**：只讲制度不改局势 → 反例判定（不得豁免）；术语多但观众不知道结果 → Process Dump 照罚；节奏过慢 → SPS < 6（每 90s 无爽点）会被一票否决，必须埋"认知碾压"型爽点（IAI 全知碾压）。

## 6. 都市写实流（Realism Flow）

- **一句话定位**：手持纪实感、自然光、真人质感，现实就是最大的戏剧。
- **视觉语法**：手持微晃；自然光/窗户光；跟拍+偷拍视角（符合"证据化载体"）；空间真实（工位/出租屋/医院走廊）。
- **节奏参数**：接近真实时间流速但保持落锤；每集 ≥1 次 Job Highlight 三要素（结果句/证据载体/局势改变）；每 3 集 ≥1 次专业打压。
- **声音设计**：环境声真实（键盘/电梯/电话）；少配乐，关键时刻才进。
- **表演指导**：生活流表演，拒绝舞台腔；职业动作专业可见（道具/文件/操作真做）。
- **适配**：职场/现实向/家庭伦理/证据链情感悬疑（Type B NON_SUSPENSE）。
- **体系联动**：ACF_B_1（Job Highlight）≥14 硬指标；PSD 成年人动机闭环（生存/利益/不可逆代价）必查；U3 显性信息载体（转账提示/聊天/文件特写）是此风格的爽点出口。
- **踩雷提示**：职业纪录片化/流程教学 → Job Highlight 直接降档；"我很专业"台词无证据 → 装逼式高光 0 分；高危行为无动机闭环 → PSD FAIL -10。

## 7. 轻喜沙雕流（Comedy Flow）

- **一句话定位**：快剪夸张表演、字幕梗鬼畜，反常识即正义。
- **视觉语法**：夸张景别（鱼眼/大特写/偷窥位）；定格+吐槽字幕；鬼畜/慢放/快进制造笑点；同一场景反复变体。
- **节奏参数**：镜头 1–2s；每集 ≥2–3 个可剪梗点（梗锤）；梗必须升级（同场景复用仍能升级，否则 L4 红）。
- **声音设计**：音效密集（duang/叮/倒带）；BGM 随时变奏配合反转。
- **表演指导**：外放表演；表情包级反应镜头；配角稳定产梗（功能稳定）。
- **适配**：沙雕漫/反套路/荒诞喜剧（Type C）。
- **体系联动**：C-Fit 五项（梗锤密度/反差覆盖/荒诞自洽/角色功能/结构升级）；落锤=梗锤（前 10 集 ≥9 集有梗锤=绿）；L1 倒计时可弱化但必须梗链升级。
- **踩雷提示**：梗重复不升级 → L4 红；荒诞规则不一致（离谱但必须自洽）；梗压过故事 → B+3 骨架塌（单集无回报）。

## 8. 信息解说流（Info-Pacing Flow）

- **一句话定位**：画面+旁白强同步，信息位移即爽点，翻案链驱动。
- **视觉语法**：V-Sync 铁律（说到什么物件，画面必须同步出现）；UI/图表/文档可视化（证据链/关系图/倒计时）；快速切镜贴旁白节奏。
- **节奏参数**：每 15s 一个钩子；每集 ≥1 次信息结算（翻案/锁定/排除）；信息密度高但旁白一句一画面。
- **声音设计**：旁白主导（口语化、有钩子句）；关键信息音效强调。
- **表演指导**：反应镜头做"信息接受者"（观众代偿视角）。
- **适配**：解说漫/翻案链/高密度信息流（Type D）。
- **体系联动**：IV 权重最高（0.35）：资产化信息位移 + Source Trace（来源可追溯）+ V-Sync + 术语负担控制；每 1–2 集必须新增关键信息推进真相链（L1 Type D）。
- **踩雷提示**：念说明书 → Process Dump（每处术语 1 句人话 + 1 步结果镜头）；来源凭空掉落 → untraced_asset 封顶；连续 2 集信息增量≈0 → L4 红。

## 9. 高级文艺流（Auteur Flow）

- **一句话定位**：长镜头隐喻构图、色彩美学，用视听语法承载认知升级。
- **视觉语法**：长镜头（15s+）内完成信息与情绪；隐喻构图（镜面/框架/留白）；色彩分级讲故事（冷→暖=关系变化）；声画对位错位。
- **节奏参数**：节奏自主但每 90s 必须仍有可剪交付（SPS 守恒不可豁免）；情绪/认知落点密集。
- **声音设计**：声音设计即叙事（环境音拟人/音乐提前介入）；留白处用噪音/呼吸。
- **表演指导**：极简表演，靠调度与光影。
- **适配**：精品短剧/品牌向/高预算项目；认知升级型神作（L5-A 认知范式升级）。
- **体系联动**：L5-A 有效推进（认知升级/秩序重定义）是此风格免于"水剧情"的依据；6.13A 豁免保护仪式感；但 SPS_Score_0_10 < 6 仍一票否决（必须把文艺表达落成可剪点）。
- **踩雷提示**：为留白而留白 → U1/U2 FAIL（看不懂）；长镜头无交付 → SPS 稀释 + PCG-2 不可执行；高级感无证据 → Process Dump 不豁免。

## 风格一致性校验（评估时使用）

- **风格锁定**：确认所选风格后，评估按该风格的标准校验"是否达标"，不按其他风格标准误杀。
- **越界检查**：主风格之外出现大面积异质镜头语言（如权谋克制流突然出现鬼畜字幕）→ 标 `Style_inconsistency`，进改稿建议（审美级，不决定 Pass/Reject）。
- **风格与规则冲突时**：规则优先于风格（如 SPS 守恒、合规 C2、肢体红线不可被风格豁免）。
