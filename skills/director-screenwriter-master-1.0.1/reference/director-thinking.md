>
# 模式4：导演思维（分镜 / 视听 / 调度）

> 目标：把剧本文字转化为**可拍摄、可执行、可投放**的视听方案。
> 核心：导演思维 = 镜头设计 + 场面调度 + 节奏剪辑 + 表演与声音 四大职能，全部服务一个目标——**让观众在竖屏 90–180 秒内看懂、爽到、记住**。

## 1. 短剧导演的硬约束（区别于长剧）

| 约束 | 要求 |
|---|---|
| 竖屏构图（9:16） | 单主体构图优先；横向信息必须拆成纵列递进；群戏靠"叠层+焦点切换" |
| 单集 90–180s | 一集一个"钩子→交付→落锤"闭环；无铺垫自由 |
| 前 3 秒 | 第一镜头必须可剪可投；禁止 logo/环境慢起（U2A 首屏失败） |
| 素材意识 | 每 90s ≥1 个"可剪爽点"（SPS）；每场戏要能截出投放切片 |
| 理解税 | 15s 内三问可复述；90s 内结果句可复述（U1/U2 硬校验） |
| 投放安全 | 单句/单镜头截取不得擦边（ARG-1）；高敏组合镜头禁用（ARG-2） |

## 2. 镜头设计（从文字到镜头）

### 2.1 每场戏的镜头转化五问

1. **这场戏观众要知道什么**？→ 确定"信息核心"，写进镜头（台词/UI/行为结果三选一，U3）。
2. **情绪落点在哪**？→ 给情绪镜头留足时间（反应镜头/特写/静默）。
3. **落锤怎么拍**？→ 落锤必须"结果可见"：推镜+定格+爽音效；不是靠台词宣布。
4. **能不能剪**？→ 每场戏至少 1 个 3–5 秒的可剪片段（有起有落）。
5. **拍不拍得起**？→ 形变/特效/场景必须可代偿可简化（DCF）；写不了的镜头改为"可见结果替代"。

### 2.2 景别节奏模板（单集 90–120s 示例）

```
0–3s     极端特写/强冲突镜头（钩子，可剪可投）
3–15s    中景+正反打（15s 三问答题：目标/阻碍/代价）
15–90s   交付推进（R类规则证据/P类成果到账，穿插特写反应）
90s 前   第一次爽点交付（落锤镜头：推镜/定格/闪白）
中段     冲突升级（2 条压强线交叉剪辑）
结尾     新钩子（悬念镜头/倒计时/威胁逼近），接 SW 或新危机播种
```

### 2.3 竖屏构图纪律

- 主体居中偏上（拇指区安全）；双人戏用"上下叠构"或"过肩+前景"替代左右分屏。
- 字幕/UI 是构图元素（金句、倒计时、判定面板），参与信息交付（U3 载体）。
- 信息密度守恒：画面元素 ≤3 层，超载即"高理解成本场景"（U3 FAIL）。

## 3. 场面调度（Blocking）

- **调度即叙事**：站位变化表达关系变化（同框→分离→同框=关系弧线）；高位者"俯视+固定位"，低位者"仰视+被围"。
- **动作线清晰**：谁打谁、谁赢、赢在哪一步——拆成"起手/中段/结算"三拍，任何一拍不可省略（PCG-2 可执行）。
- **群体戏**：焦点由"站位+光"决定，观众必须一眼知道"该看谁"。
- **空间真实**（Type B）：工位/病房/出租屋等场景细节（文件、输液瓶、账单）本身就是"证据化载体"（Job Highlight）。

## 4. 节奏剪辑（Pacing）

- **卡点**：爽点/反转/金句与 BGM 重拍对齐；落锤后给 0.5s 静帧让观众"接住"。
- **SW 结算窗口**：重大胜利后 30–60s 纯净结算（享受战利品/对手受罚），禁止插入新主线危机；新危机在窗口后下一场或下一集开头播种。
- **焦虑跑步机预警**：连续 ≥3 集"解决→立刻更大危机"且无 SW → 黄牌；≥5 集 → 红牌。
- **同构疲劳**：同一场景+同对话结构+同解决方式重复且增量≈0 = 同构（L4）；破局方式必须异构（VIS_Diversity/OPK）。
- **静默协议（U4）**：纯镜头语言段落 ≤6s 或 ≤3 镜头，且必须承载信息交付；超过即按高理解成本处理。

## 5. 表演与声音（Performance & Sound）

- **反应镜头是短剧的"第二台词"**：打脸后必须有"瞳孔地震/嘴角上扬/围观群众变脸"等反应剪辑（SGM 认知崩塌的可视化）。
- **声音设计三原则**：① 台词第一（可口型/可复述）；② 音效即证据（转账提示音/盖章声/心跳=信息载体）；③ BGM 是节奏引擎（风格库规定各风格的声音语法）。
- **旁白纪律**：Type D 旁白一句一画面（V-Sync）；其他类型旁白不得承担"解释唯一来源"（要靠镜头/台词/UI 讲清）。

## 6. 剧本 → 分镜转化清单（输出物）

将剧本场景逐场转化为分镜方案，每场输出：

```
【分镜卡】Ep{集} 场{序}
场景/地点：______
时长：___s｜风格：______
信息核心（U3 载体）：台词□ / UI文字□ / 行为结果□ → 具体：______
镜头序列：
  1. 景别/运镜/时长｜画面内容｜声音｜字幕/UI｜（可剪点 Y/N）
  2. ...
情绪/表演要点：______
落锤镜头：______（推镜/定格/闪白/爽音效）
SW 结算：有□ 无□（若为胜利场次必须规划）
合规自查：无截屏风险□ / 肢体分级合规□ / 高敏组合□
```

## 7. 导演向自检清单

- [ ] 前 3 秒镜头可剪可投
- [ ] 15s 三问镜头可复述（U1）
- [ ] 90s 首次交付镜头存在（U2：R类/P类/悬疑等价）
- [ ] 每 90s ≥1 个可剪爽点（SPS），且爽点有"社会代价/认知崩塌"落点（SGM 非互殴）
- [ ] 落锤镜头可见（推镜/定格/UI 判定，非台词宣布）
- [ ] 竖屏构图合规（单主体/上下叠构/信息 ≤3 层）
- [ ] 无不可执行镜头（PCG-2）；形变/特效可代偿（DCF）
- [ ] 静默场景 ≤6s 且承载交付（U4）
- [ ] SW 结算窗口已规划（Ep3 后）
- [ ] 破局方式异构（VIS_Diversity/OPK）
- [ ] 肢体互动分级合规（≤2s 直接给；2–5s 遮蔽代偿；>5s 禁止）
- [ ] 风格一致性（镜头语言符合所选导演风格，见风格库）
- [ ] 无截屏风险/高敏组合（ARG）

## 8. 与编剧模式的协作

- **编剧先行**：故事核 → 剧本文字（含镜头提示）→ 导演转化。
- **导演回改**：导演发现"拍不出来/理解成本高/爽点不落地"时，有权回改剧本（结果前置/一句话人话/镜头证据化三原则）。
- **双轨合一**：创作时直接"文+镜"双栏输出（台词栏 + 镜头栏），评估时两栏分别按评估模式与本文校验。
