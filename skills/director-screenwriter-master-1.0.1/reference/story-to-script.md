# 模式3：故事 → 优秀剧本

> 目标：把故事/IP/大纲变成**可拍摄、可投放、可连载**的短剧剧本。核心纪律：**结果前置、一句话人话、镜头证据化**（SPS 守恒）。
> 流程：选风格 → 故事核 → 类型路由 → 首集工程 → 单集模板 → 五维骨架 → 连载结构 → 角色设计 → 爽点质量 → 风格落地 → 红线自检。

## 0. 确认导演风格（必选第一步）

- 用户指定 → 直接采用；未指定 → 按题材/Type 从[风格库](director-styles.md)推荐并确认。
- 写作全程按风格约束执行：镜头提示、节奏参数、视听语法（见风格库对应条目）。
- 单集主风格唯一；多风格项目需设计切换点过渡。

## 1. 故事核提炼

- 一句话讲清：**主角是谁 + 要什么 + 谁阻止 + 失败代价**（15 秒三问）。
- 提炼 **12 字主爽点**：能一句话说完的核心爽感（如"赘婿三年，一朝龙归"）。
- 明确主爽点的**心理代偿链**：匮乏（观众缺失什么）→ 补偿路径（剧情怎么补）→ 爽点（可剪的结果镜头）。

## 2. 类型路由

按受众倒推（见 SKILL.md）定 Type A/B/C/D，并标注 Type B 子类型：
- `NON_SUSPENSE`（婚恋/复仇/职场/家庭伦理/权力博弈）
- `SUSPENSE`（案中案/线索链/翻案链）→ 启用悬疑等价交付 + M-Scan 设计

## 3. 首集工程（Ep1 四个强制检查点）

1. **3 秒钩子**：第一镜头/第一句必须可剪、可投放（拒绝氛围铺垫开场）。
2. **15 秒答题**：观众知道"为什么要看下去"（目标/阻碍/失败代价）。
3. **60 秒冲突树**：至少 2 条压强线并行（如：职场打压线 + 家庭债务线）。
4. **结尾钩子**：下集必看理由（新威胁/新谜面/不可逆代价倒计时）。

**一卡高潮阈值（U2A）**：前 1–2 集必须出现 ≥1 次"高潮级事件"，三要素满足任意两项：
- 不可逆代价（工分/名声/资源断供/处分/生命倒计时）
- 公开场域对抗（权威/人群/组织见证，可被切片传播）
- 主线推进落锤（目标从口头变成行动证据：抓到证据/签下契约/被迫站队）
- 前 1–2 集只有日常互动/斗嘴/吃饭/谈心 → FAIL（首屏失败，FinalScore -= 5，标记 PCG_warning）。

## 4. DW-90 二段式（每一集都要设计）

- **15s 内答题**：观众知道（目标/阻碍/失败代价）。
- **90s 内首次交付**（二选一）：
  - **R 类（Rule Proof）**：规则证据化交付（展示规则样本/后果/契约条款/UI 判定）
  - **P 类（Payoff）**：成果型交付（能力/证据/资产/地位 之一到账）
- 悬疑分支等价交付：线索交付 / 排除锁定 / 危机升级 / 不可逆代价。
- **不允许** 90s 内"只有解释、无交付"。

## 5. 单集模板（落锤 + 小回报）

- **落锤定义**：单集内出现事实/权力/身份/资源/规则/舆论/法律结果的**落地变化**（不是吵架）。
- 每集至少 1 个可结算的小回报（单集闭环）；连续 3 集无回报 → B+3 子项 4 封顶 10。
- 结算窗口（SW）：重大胜利后给 30–60 秒"纯净结算"（享受战利品/对手受罚），窗口内禁止引入新主线危机；新危机在窗口结束后的下一场或下一集开头播种。
- 频率红线：Ep3 起算，连续 ≥3 集"解决小麻烦→立刻更大危机"且无 SW → 黄牌；连续 ≥5 集 → 红牌（焦虑跑步机）。

## 6. 五维骨架（对照自检）

| 维度 | 设计要点 |
|---|---|
| **SPS 内容价值** | 12字主爽点清晰；心理代偿链完整；金句口语化/强指向/可站队/视觉化；评论区对立与站队驱动；短句可屏摄可口型（每 90s ≥1 个可剪爽点：打脸/翻盘/惩罚/资源位移/证据锁死） |
| **CAP 性格力** | 性格公理 2+1（Never/Always/Priority）；主角动机稳定不靠降智；反派/系统人格一致；关键关系张力可持续 |
| **B+3 硬骨架** | DW-90 达标；跃迁必有台阶（规则/证据/验证）；兑现是结果型而非解释回收；单集小回报；中段每 N 集注入新变量且结局不崩设定 |
| **APM 叙事动能** | 每 3 集 ≥1 次专业打压 + ≥1 次系统不可逆压强；升级链连续（压制→反弹→更大压制）；反转改变位阶/关系/资源；钩子间距可控 |
| **VIS 视觉张力** | 人物/怪物/道具辨识度；特效溢价空间；形变压力可控（可代偿/可简化）；UI 是叙事价值非遮挡；动作可拆镜头 |

**加分项 CAP+ 反差标签**（主角记忆钩子，二选一）：
- Type I 性格反差：斯文暴徒/极度礼貌的狠人（对立但自洽）
- Type II 身份/能力错位：外在低微、内在碾压（扫地僧），必须"来源可追溯 + 现实可成立"（Ep1–Ep3 证据化）；若现实锚点弱（ACF_B_1 < 14）则 Type II 最高 10 分
- 反差须在 Ep1–Ep3 出现 ≥2 次"反差同框"动作证据，且服务于高风险行为闭环。

## 7. 连载结构（L5 套娃连通）

- **禁止"主线危机完全闭环"**：单集/单元小胜负可闭环（保落锤密度），但主线危机必须被推高/暴露更深层对手/制造不可逆损失。
- 设计因果链：**事件 → 后果 → 更大危机**，每解决一个小麻烦必须触发更大的事。
- 写完后做**删集测试**：删掉 Ep4/5/6 的任一集，Ep10 结局是否必须改？答"否" → 该集是水剧情，重写。
- **L5-A 有效推进**（无更大危机时也算 PASS）：关系不可逆推进（死敌转暗盟/性命托付）/ 秩序规则重定义（夺取解释权/执行权/裁定权）/ 认知范式升级（误导拆穿/真相链重组）——但必须改变后续决策链与人物站位，删集测试为 MustRewrite。

## 8. 角色设计

### 主角
- 性格公理 2+1（Never/Always/Priority）+ 反差标签（见上）。
- 动机必须成年人闭环（PSD）：高风险行为（闯婚礼/公开羞辱权势者/非法交易/以命换局/当众下跪求生）必须有**生存压力 / 巨大利益 / 不可逆代价**任一闭环；"为了泄愤/面子/装逼" → FAIL（FinalScore -= 10）。

### 反派（RCC-M 三问闭环）
前 10 集内反派每次重大行动必须同时回答：
1. **要什么**：可量化收益（身份位/资源位/名声/指标/生存）
2. **怎么拿**：行动手段与策略
3. **如何承受风险**：法律/权力/生存风险如何被规避或可承受

风险匹配原则：掉脑袋级风险（烧公物/叛国指控/致命谋杀）的动机不得停留在"吃醋/轻度嫉妒"，必须升级为同等级收益或自保。FAIL → FinalScore -= 5，标 RCC-M_villain_incoherent。

### 双主角/多主角（CFS 平衡）
前 10 集每位核心主角必须：各自 ≥2 次"关键破局动作"（推动主线，非陪聊）+ 各自 ≥1 次"公开落锤"。FAIL → 标 CFS_duallead_imbalance，输出功能位重构任务单（谁负责伪装/证据链/公开落锤）。

### 关系线（RRL 升温坡度，女频/关系驱动必做）
前 10 集至少 3 级关系台阶（允许分布在不同集）：
1. **公开站队**：外部压力下公开维护/背书
2. **共担代价**：一起背锅/一起损失资源或名声
3. **共享秘密（不可撤回）**：共享关键秘密/共同违法或违规/共同承诺

只有口头甜/突然关心/态度瞬变 → FAIL（标 RRL_relationship_jump，Verdict 上限 Revise）。

## 9. 爽点质量设计（SGM 社会心理矩阵）

每个关键高潮至少命中一个高质量爽点形态，拒绝"隔靴搔痒"：

| 指标 | 满分形态（20分） | 及格（10分） | 零分（扣分项） |
|---|---|---|---|
| **IAI 信息差势能** | 全知碾压：观众+主角握核弹级筹码，反派狂妄，揭晓瞬间瞳孔地震；或绝境盲盒（悬疑优先） | — | 认知同频：只能靠互殴/运气推进 |
| **SCPR 社会资本剥夺** | 杀人诛心：社会性死亡（背书崩塌/权力反噬/当众下跪被弃），主角夺解释权 | 物理降维：仅武力/金钱击败 | 隔靴搔痒：只动口舌/警告/小惩罚 |
| **ELR 情绪杠杆** | 核爆杠杆：极短支点铺垫→毁灭性释放，观众瞬间回血 | 线性对冲：你来我往 | 疲劳通胀：铺垫过长/反击过软 |

写作纪律：
- 复仇/权谋/鉴渣/职场清算类：高潮必须包含"社会资本剥夺"（诛心而非吵架），否则判"只会吵架"。
- 悬疑分支：允许绝境盲盒为满分形态；SCPR 可延迟结算，但前 10 集必须出现 ≥1 次诛心或 ≥2 次物理降维。
- 每个爽点必须可证据化（观众可感知的认知崩塌/社会性死亡/支点-爆点），不得只靠旁白。

## 10. 风格落地（按所选导演风格写"可拍"的剧本）

- 剧本中写出**镜头提示**（景别/运镜/卡点/音效），供导演模式直接转分镜；风格参数（镜头均长、爽点形态、声音语法）从[风格库](director-styles.md)对应条目取用。
- 风格与规则冲突时：**规则优先**（SPS 守恒/合规 C2/肢体红线不可被风格豁免）。
- 风格回改机制：导演模式发现"拍不出来/理解税高/爽点不落地" → 按三原则回改剧本（结果前置/一句话人话/镜头证据化）。

## 11. 落地纪律（防"写得出拍不出"）

- **U5 术语落地**：每处术语/流程/规则 = **1 句人话解释 + 1 步结果镜头**（UI/实物/录音/当众指认）。连续 ≥3 句术语且无结果交付 = Process Dump（每次 FinalScore -= 3、SPS -= 1）。
- **6.13A 高级感豁免**：连续 ≥3 句术语若承担"权力/制度威压"+"延时闭环交付/服务 SGM 高分项"任意两项 → 不计 Dump（权谋/制度戏保护条款）。
- **U6 系统极简**（系统/面板/数值/抽卡类）：前 5 集内系统规则条件语句 ≤2 层（单层：杀敌→积分→换武器；双层：杀敌→积分→积分受等级影响→换武器；>2 层直接 FAIL）；同一集 ≤1 次换算解释；解释后 60 秒内必须"立刻到账"（R 类/P 类交付）。改法：1 句人话规则 + 1 个 UI 提示 + 1 个立刻生效的结果镜头。
- **RCC 系统四要素**：系统/金手指必须至少三项清晰——触发条件/代价/收益/限制（冷却/次数/场景闸/反噬）。
- **Job Highlight 职业高光**（Type B）：职业动作必须同时满足"结果句 + 证据化载体（UI/纸面证据/条款/鉴定报告，或偷拍/录音/实物/监控）+ 局势改变"；只有"我很专业"的台词 → 装逼不给分。
- **Source Trace 来源追溯**：能力/证据/资产/地位到账必须有来源（规则奖励/契约交换/清算夺取/代价置换），禁止凭空掉落。
- **肢体互动分级**：≤2s 接触允许；2–5s 必须给遮蔽代偿镜头（切黑/背光/特写跳切）；>5s 深吻/贴身缠斗/复杂肉搏禁止，改写为"靠近停顿+转场/遮挡"。
- **视觉异构降维**（Type A/大招流）：同一核心道具/同一特效连续 3 次解决同级别危机后，第 4 次必须异构（道具失效/弹药耗尽/近战/地形反杀/交易破局/不可逆代价）。

## 12. 成稿自检清单（编剧 + 导演双轨）

- [ ] **风格已确认**：风格 = ______（未确认不得开工）
- [ ] 题眼兑现 U7：前 2 集 ≥1 处题眼具象化；前 10 集 ≥3 处（高概念类）
- [ ] 一卡高潮 U2A：前 1–2 集有不可逆代价级事件
- [ ] 反派闭环 RCC-M：重大行动通过三问
- [ ] 双主角平衡 CFS：各自破局 + 公开落锤（多主角类）
- [ ] 关系坡度 RRL：3 级台阶证据（关系驱动类）
- [ ] DW-90：15s 答题 + 90s 交付（R/P）
- [ ] 每 90s ≥1 个可剪爽点，且 SGM 至少一档高分（非互殴/运气）
- [ ] 删集测试通过（主线不闭环、套娃连通）
- [ ] 无 Process Dump、系统 ≤2 层、资产有来源、镜头可执行
- [ ] 合规 C0/C1（无细节化过程呈现）、无截屏风险
- [ ] **导演向**：前 3 秒可剪可投 / 落锤镜头可见 / 竖屏构图 / 静默 ≤6s / SW 已规划 / 破局异构 / 肢体分级合规 / 风格一致（详细见导演思维模式）

> 自检 FAIL 项：直接按对应条款改稿后再交付，不要带着已知 FAIL 进入评估环节。
