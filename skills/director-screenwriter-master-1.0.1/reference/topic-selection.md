# 模式1：选题（立项评估）

> 目标：把一个点子/题材/IP 变成**可立项**的项目，回答四个问题：给谁看（受众）→ 用什么载体讲（Type）→ 风险与匹配度如何（ACF/合规）→ **用什么导演风格拍**（风格适配）。

## 流程

1. 确认输入：题材/故事/点子/IP，目标市场（国内/海外），目标受众（男频/女频/泛娱乐），单集时长（90–180s），总集数，预算档位。
2. 受众倒推路由（见 SKILL.md）：定 Type A/B/C/D。
3. 跑题材适配度（ACF-A / ACF-B / C-Fit）与题材适配基准。
4. 高概念可兑现性预检（U7 视角）：设定是否能在**前 2 集**具象化落地，避免"只卖概念"。
5. 平台合规预检（C0/C1/C2）与可截屏风险预检（ARG-1）。
6. 市场雷达：爽点是否过期、话术是否可二创、同赛道差异点。
7. **推荐导演风格**：按题材从[风格库](director-styles.md)速查表取首推/备选风格，评估预算与执行可行性。
8. 输出《选题卡》。

## 题材适配度

### Type A（视觉奇观权力爽）ACF-A 六维（0–100）

| # | 维度 | 权重 |
|---|---|---|
| 1 | 视觉爽点承载 | 25 |
| 2 | 设定/世界观容忍度 | 15 |
| 3 | 动作/场面表达收益 | 15 |
| 4 | 画面驱动叙事 | 15 |
| 5 | 情绪与风格一致性 | 15 |
| 6 | 平台心智匹配 | 15 |

题材适配基准（用于第6项/综合判定）：
- **S档（18–20）**：玄幻/修真/异能/系统流；江湖/权谋+战斗；奇幻冒险氛围向；机甲/未来都市；规则改写升级
- **A档（14–17）**：都市逆袭/复仇打脸（需强视觉落锤）；轻悬疑（线索必须可视化）；轻喜剧（画面梗为主）
- **B档（9–13）**：强现实婚恋/家庭伦理/写实职场/重心理对白（更适配 Type B）
- **C档（0–8）**：高密度翻案证据链（更适配 Type D）；纯无厘头梗剧（更适配 Type C）

裁定：≥75 强支持 Type A；60–74 需给"视觉化改造方案"后可上；<60 转 Type B/C/D。

### Type B（现实题材/真人质感）ACF-B 五维（0–100）

| # | 维度 | 权重 |
|---|---|---|
| 1 | 现实锚点与代入感（含职业高光性 Job Highlight） | 20 |
| 2 | 情绪回报适配真人质感 | 25 |
| 3 | 题材天然适配度 | 20 |
| 4 | 叙事承载方式匹配 | 20 |
| 5 | 预期一致性与雷区 | 15 |

题材适配基准（用于第3项）：
- **S档（18–20）**：现言婚恋、复仇打脸、家庭伦理、职场逆袭、真假千金（现实向）、证据链情感悬疑
- **A档（14–17）**：轻悬疑、轻奇幻（设定极少）、古风但现代情绪逻辑
- **B档（9–13）**：重礼制古装/重权谋、重设定奇幻（容易"我不信"）
- **C档（0–8）**：战争群像/硬科幻/大量非现实生物（建议转 Type A 或 D）

裁定：≥75 强支持 Type B；60–74 需补"真人质感下的结算方式/预期一致性"后可上；<60 转 Type A/D。

### Type C（沙雕漫）C-Fit 五维（每项 0/5/10/15/20）

1. 梗锤密度（每集至少 2–3 个可剪梗点）
2. 反差类型覆盖（身份/认知/因果/语义 至少命中 2 类）
3. 荒诞规则一致（离谱但自洽）
4. 角色功能稳定（稳定产梗/制造误会/推动反差）
5. 结构反复可升级（同场景复用仍能升级）

裁定：≥70 强支持 Type C；50–69 需补"梗链升级/反差来源"后可上；<50 转 Type A/B/D。

## 高概念可兑现性预检（U7）

适用范围：高概念错位身份/关系喜剧/强设定宣称类（人前婆媳人后闺蜜、双穿错位、假情侣、替身错位等）。

- 前 2 集能否出现 ≥1 处"题眼具象化场景"（人前人后反差闭环同集成型，或题眼机制推动一次公开落锤）？
- 只有设定说明/口头宣告、无落地动作 → **判定不可立项或必须补题眼落地设计**（FinalScore -= 5、Verdict 上限 Revise）。

## 合规预检（C0/C1/C2）

- **C0（PASS）**：仅未成年年龄/身份台词；处置/威胁台词（无过程细节）；远景/转场暗示。
- **C1（PASS + 风险标签）**：轻描淡写的伤害结果（无过程细节）；恐怖/血腥氛围词但无"未成年被霸凌/虐待/残虐细节"过程描写。
- **C2（FAIL 熔断，不进入计分）**：详细霸凌细节（过程/羞辱动作/持续呈现）；详细虐待细节（折磨过程/残虐动作/反复描写）；未成年性侵害/性剥削/恋童相关的任何可识别细节。
- 海外画像可放宽血腥/暴力阈值，但仍保留 C2 的未成年细节化虐待/性剥削硬熔断。

## 商业硬闸预检（ARG）

- **可截屏风险**：任一集存在"单句/单镜头截取即可构成擦边、侵犯暗示、低俗挑逗、未成年敏感、群体仇恨/现实指向"的素材 → 选题阶段即标记，必须给替代句/替代镜头方案。
- **高敏组合镜头**：`衣衫不整+惊恐/挣扎+追逐/按倒/贴身拉扯`、`低俗口语+性暗示动作` 等平台高敏组合 → 标记"投放安全版"成本。

## 导演风格适配（选题阶段即定调）

- 按题材取首推/备选风格（速查表见[风格库](director-styles.md)）。
- **预算联动**：视听奇观流/高级文艺流需要高预算档位；都市写实流/轻喜沙雕流适合中低预算。
- **执行可行性**：风格要求的镜头复杂度（长镜头/特效/大场面调度）必须与预算档位匹配，否则降级风格或标记成本风险（DCF 预判）。
- 风格影响投放素材：卡点爽感流/轻喜沙雕流素材切片率高；权谋克制流/高级文艺流切片率低但口碑溢价高——按投放策略选择。

## 选题卡输出模板

```
【选题卡】
剧名/暂定名：______
一句话梗概（12字主爽点）：______
目标受众：______ / 目标市场：______
匹配载体：Type ___（路由理由：______）
推荐导演风格：首推______ / 备选______（预算联动：S/A/B/C 档）
ACF 得分：ACF-A/B/C-Fit = ___（档位：强支持/可上/不建议）
高概念可兑现性：U7 = PASS/FAIL（证据：______）
合规预检：C0/C1/C2（风险标签：______）
商业风险：ARG 截屏风险 Y/N / 高敏组合 Y/N
市场雷达：爽点新鲜度 / 同赛道差异点 / 话术二创空间 / 风格差异化
立项建议：推荐立项 / 修改后立项 / 备选 / 不立项（理由：______）
```

## 关键联动

- ACF < 60 → 该载体不建议，转型或放弃；ACF 60–74 → 需改造方案后上。
- 复仇/权谋/鉴渣/职场清算类选题：评估时 SGM 的 SCPR（社会资本剥夺）必须可达（见评估模式），"只会吵架"的选题慎立。
- 风格与题材错配（如权谋题材选轻喜沙雕流）→ 选题阶段即提示换风格，避免立项后返工。
