> **EN:** Mode 2 Story optimization: upgrades existing stories/outlines from “tellable” to “viral” before scripting — diagnose first, evidence-based fixes, never sacrifice satisfaction-point density (SPS conservation).
>
# 模式2：故事优化（故事诊断与升级）

> 目标：把已有故事/大纲/点子从"能讲"升级为"能爆"。在写剧本之前，把故事层的病灶（冲突疲软、爽点隔靴搔痒、人物动机不闭环、连载会断）全部解决，避免带病进入改编。核心纪律：**先诊断后开方、证据化定位、优化不得牺牲爽点密度（SPS 守恒）**。
> 流程：确认输入 → 故事核诊断 → 载体路由 → 冲突引擎 → 爽点工程 → 人物优化 → 结构优化 → 差异化与风险 → 输出优化报告 + 优化后大纲。

## 0. 确认输入与项目参数

- 输入：故事梗概 / 大纲 / 人物设定 / 核心创意（任意形态，允许只有一句话；已有剧本的请走[评估模式](script-evaluation.md)）。
- 项目参数：目标市场（国内/海外）、目标受众（男频/女频/泛娱乐）、单集时长（90–180s）、总集数、预算档位。
- 导演风格可在本模式结束后由[改编模式](story-to-script.md)确认（故事层优化不依赖风格）。
- 交付物：《故事优化报告》+ 优化后故事大纲（12 字主爽点 / 人物卡 / 冲突链 / 首集钩子设计 / 连载路线图）。

## 1. 故事核诊断（15 秒三问）

- **三问**：主角是谁 + 要什么 + 谁阻止 + 失败代价，一句话讲清。
- **12 字主爽点**：能一句话说完、可传播的核心爽感（如"赘婿三年，一朝龙归"）。
- **心理代偿链**：匮乏（观众缺失什么）→ 补偿路径（剧情怎么补）→ 爽点（可剪的结果事件）。
- 判定：三问任一答不清 → 故事核 FAIL，必须先重构故事核再继续，不得带模糊故事核做后续优化。
- 换汤检查：把主角换成路人，故事是否仍然成立？成立 → 主角缺不可替代性，故事核不成立（FAIL）。

## 2. 载体路由与匹配快检（先受众后条件）

- 按受众倒推（见 SKILL.md）定 Type A/B/C/D，标注 Type B 子类型（NON_SUSPENSE / SUSPENSE）。
- **ACF 快检**：故事与载体的匹配度——
  - Type A：视觉承载度（奇观/动作是否叙事主体）、设定容忍度
  - Type B：现实锚点与代入感、情绪回报真人质感
  - Type C：梗锤密度（每集 ≥2–3 个可剪梗点）、反差类型覆盖
  - Type D：信息位移资产化、翻案链/解说链驱动
- 快检 FAIL → 给**转型方案**（换载体/换讲法/换题材侧重），不硬优化；确认转型后再继续。

## 3. 冲突引擎优化

- **主冲突存在性**：冲突双方的诉求是否可量化、可持续（可升级、可结算），还是"误会→解释→和好"一次性矛盾？
- **60 秒冲突树**：≥2 条压强线并行（如职场打压线 + 家庭债务线），防止单线故事 10 集内枯竭。
- **反派闭环 RCC-M 三问**：要什么（可量化收益）/ 怎么拿（手段与策略）/ 如何承受风险（法律/权力/生存规避）。掉脑袋级风险必须匹配同等级动机或自保需求，防"反派降智"。
- **升级链**：压制 → 反弹 → 更大压制，连续 ≥3 级；反转必须改变位阶/关系/资源（不是"打赢了又来了一个"）。
- **不可逆代价**：故事层必须有"输了会失去什么"的硬代价（资源/身份/性命/关系）；主角永远零代价 → 故事无张力（WARN，需设计代价项）。

## 4. 爽点工程优化（SGM 视角）

- 主爽点落到 **SGM 高分形态**（详情见评估体系）：
  - **IAI 信息差势能**：全知碾压/绝境盲盒（主角握筹码，反派狂妄，揭晓即认知崩塌）
  - **SCPR 社会资本剥夺**：诛心级事件（社会性死亡/背书崩塌/当众下跪被弃/夺解释权）
  - **ELR 情绪杠杆**：极短支点铺垫 → 毁灭性释放
- 复仇/权谋/鉴渣/职场清算类：必须能设计出"诛心"级事件，只有"吵架/警告/小惩罚" → 主爽点 FAIL（防"只会吵架"）。
- **可剪事件预演**：把打脸/翻盘/惩罚/资源位移/证据锁死五类事件按时间轴铺在故事线上，保证每 90s ≥1 个可剪爽点的事件密度（故事层预演，改编时落成镜头）。
- 悬疑分支：允许绝境盲盒为满分形态；SCPR 可延迟结算，但前 10 集必须 ≥1 次诛心或 ≥2 次物理降维。

## 5. 人物优化

### 主角
- **性格公理 2+1**：Never（永不做什么）/ Always（总是做什么）/ Priority（第一优先）。
- **动机 PSD 闭环**：高风险行为（公开对抗权势者/非法交易/以命换局）必须有生存压力 / 巨大利益 / 不可逆代价任一闭环；"为了泄愤/面子/装逼" → FAIL。
- **反差标签 CAP+**（二选一）：Type I 性格反差（斯文暴徒/极度礼貌的狠人）或 Type II 身份/能力错位（扫地僧，需"来源可追溯 + 现实可成立"）；反差须能设计出 Ep1–3 的"反差同框"动作证据。

### 反派与配角
- 反派过 RCC-M 三问（见第 3 节），且必须有升级路径（后期对手更强/更深层）。
- 配角功能位清单：谁制造压强 / 谁交付信息 / 谁升温关系 / 谁负责笑点——任一功能位空缺 → 补人物，防"工具人凑数"。

### 关系线（关系驱动类必做）
- **RRL 三台阶**（允许分布在不同集）：公开站队 → 共担代价 → 共享秘密（不可撤回）；只有口头甜/突然关心 → FAIL（标 RRL_relationship_jump）。

### 双主角/多主角（CFS 平衡）
- 每位核心主角：各自 ≥2 次"关键破局动作"（推动主线，非陪聊）+ ≥1 次"公开落锤"；失衡 → 输出功能位重构任务单（谁负责伪装/证据链/公开落锤）。

## 6. 结构优化

### 首集工程预演（故事层版）
1. **3 秒钩子**：开场事件（不是氛围/环境介绍），必须可剪可投放。
2. **15 秒答题**：目标/阻碍/失败代价。
3. **60 秒冲突树**：≥2 条压强线并行。
4. **结尾钩子**：下集必看理由（新威胁/新谜面/不可逆代价倒计时）。
- **一卡高潮 U2A**：前 1–2 集必须设计 ≥1 次高潮级事件（不可逆代价 / 公开场域对抗 / 主线落锤，三选二）；前 1–2 集只有日常互动/斗嘴/吃饭/谈心 → 首屏失败（FAIL）。

### 连载结构
- **主线危机不闭环**：单集/单元小胜负可闭环，但每解决一个小麻烦必须触发更大的事（套娃连通）。
- **删集测试**：删掉 Ep4/5/6 的任一集，Ep10 结局是否必须改？答"否" → 该段是水剧情，重写。
- **落锤与回报规划**：每集 ≥1 个可结算的小回报（事实/权力/身份/资源/规则/舆论/法律的落地变化）；连续 3 集无回报 → 优化任务。
- **SW 结算窗口**：重大胜利后规划 30–60 秒"纯净结算"（享受战利品/对手受罚），窗口内禁止引入新危机；防"焦虑跑步机"（连续 ≥5 集无 SW 为红牌）。

### 中段变量
- 每 N 集注入新变量（新对手/新规则/新代价/新关系），且结局不崩设定（引入时预留闭环出口）。

## 7. 差异化与市场优化

- **高概念可兑现性 U7**：高概念类（错位身份/双穿/替身等）前 2 集能否出现 ≥1 处"题眼具象化事件"（人前人后反差闭环同集成型，或题眼机制推动一次公开落锤）？只有设定说明 → FAIL。
- **同赛道雷达**：12 字主爽点是否过期/烂大街；话术是否可二创；与同赛道爆款的差异点是什么（人物/结构/爽点形态/题材混搭）。
- **合规预检**：C0/C1/C2 粗筛（未成年细节化霸凌/虐待/性剥削 → 直接否决）+ 截屏风险 ARG（单句/单事件截取即擦边/敏感 → 给替代方案）。
- **海外市场**：文化折扣项检查（中式伦理语境/特定梗/制度设定在海外是否成立，是否需要本地化改造）。

## 8. 红线自检（优化前先排雷）

- **结构型问题直接建议 Reject，不进入优化**：主线危机不存在 / 动机闭环不成立 / 核心反派不可落地 / 10 集内无连载推高机制。
- **SPS 守恒**：任何优化动作不得稀释爽点密度；"逻辑满分但没爽点"= 过度矫正，必须回补可剪爽点事件。
- **悬疑清晰度**：允许"已知未知"（真凶/动机/手法可暂未知），不允许"看不懂"（发生了什么/在追什么/风险是什么必须清楚）。
- **合规硬熔断**：C2 级内容任何优化理由都不可豁免。

## 关键联动

- 故事优化结论为 **Seed** → 进入[改编模式](story-to-script.md)（模式3），优化后的 12 字主爽点/人物卡/冲突链/首集钩子设计直接作为改编输入；结论为 Revise → 按优化动作单重修故事后再改编；Reject → 建议重新选题（模式1）。
- 已完成选题（模式1）的项目：跳过重复检查，直接进入冲突引擎/爽点工程/结构优化深挖。
- [评估模式](script-evaluation.md)（模式6）发现的故事层问题（非表达/节奏型）：回本模式做"故事层重修"，不要在剧本层硬改。
- 故事层优化不得越界：不写台词、不写镜头、不写分镜——那是改编模式与导演思维模式的职责。
